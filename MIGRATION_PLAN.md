## 2. Target architecture

- **Astro 7 (static output) + TypeScript (strict) + Tailwind CSS v4** via `@tailwindcss/vite`. Every page is pre-rendered HTML at build time.
- **No React islands (deliberate).** After porting, nothing on the site needs a component runtime: mobile nav, work filters, forms, email de-obfuscation, click-to-load video and analytics consent are each a few lines of vanilla TS. Shipping React for them would cost ~45 KB+ and Lighthouse points. The existing React components were framer-motion animations, so reuse wasn't sensible; the hero flow diagram was ported to a static SVG/CSS component. `@astrojs/react` can be added later in one command when a real interactive demo widget arrives (documented in README).
- **Content collections** (`src/content.config.ts`, glob loader, Zod schemas):
  - `projects` – one Markdown file per project; images co-located under `src/assets/projects/<slug>/`.
  - `services` – the four packages (copy + deliverables); prices come from config.
  - `blog` – schema only + one draft example ("blog-ready"; no public route until the first post exists).
- **`src/config/site.ts`** – single typed source for name, tagline, email, WhatsApp, booking link, socials (TODO placeholders), analytics env names, founding-client toggle, pricing, process, FAQ, credentials, CricNexa copy.
- **Netlify:** `netlify.toml` (build, publish `dist`, Node 22, security + cache headers, 301s for every old URL), `src/pages/404.astro`, Netlify Forms (`contact`, `cricnexa-waitlist`) with honeypot. Forms are plain HTML in the static output, so Netlify's build-time form detection sees them; no detection stub is needed.
- **Analytics:** `<Analytics />` → Cloudflare Web Analytics when `PUBLIC_CF_BEACON_TOKEN` is set; GA4 only when `PUBLIC_GA_ID` is set **and** the visitor accepts the consent notice. CTA tracking via `data-track` attributes, no-op without GA.
- **SEO:** `<Seo />` component (title, description, canonical, OG/Twitter, JSON-LD), `@astrojs/sitemap`, `robots.txt` endpoint, build-time OG images via `satori` + `sharp` (`/og/*.png`), web manifest, favicon set.
- **Fonts:** self-hosted Inter Variable (`@fontsource-variable/inter`, with optical-size axis for display headings). See decision D2.

## 4. Decisions made where the brief was ambiguous
- **D1 Branch.** The brief asks for `revamp/astro-netlify`; this session is pinned to `claude/flownexahere-astro-migration-26qgl1`, so all work is on that branch (not `main`). Rename/merge it as you prefer.
- **D2 General Sans.** Fontshare's CDN was unreachable from the build environment, and loading it from their CDN at runtime is a render-blocking third-party request. The site self-hosts Inter Variable and uses its display optical size for headings, which keeps the clean grotesk look. To restore General Sans, drop the woff2 files in `public/fonts/` and follow the note in `src/styles/global.css`. Listed in REVIEW_NEEDED.
- **D3 Package manager.** npm (matches `package-lock.json` and Netlify's default). `bun.lockb`/`bunfig.toml` removed.
- **D4 Project types.** All migrated projects are `type: demo`, `status: demo` until the owner confirms otherwise. Entries without a case study (`NeuroSymbolic VQA`, `MediTranscribe`, `AuditX`) use `caseStudy: false` and render as cards without a detail page.
- **D5 Drafts.** `status: draft` entries are rendered in `astro dev` (with a DRAFT banner) and excluded from `astro build`, so they never reach production pages, the sitemap, or OG images.
- **D6 Placeholders.** Unknown values in `site.ts` start with `TODO`. Helpers hide TODO links in production builds (so visitors never see a dead link) and show a visible "TODO" marker in dev. All are listed in REVIEW_NEEDED.
- **D7 Booking link.** Until a free booking link (e.g. Cal.com free plan) is set, "Book a free 15-min call" scrolls to the contact form with "Free 15-min call" preselected.
- **D8 Pricing.** "Starting from" prices in `site.ts` are placeholders chosen to be modest; they must be confirmed by the owner before launch.
- **D9 WhatsApp number.** The existing site lists +92 317 410 0973 as the agency WhatsApp; it also appears as the founder's personal phone on the old team page. It is kept as the WhatsApp CTA (it was already public as the agency contact) and flagged for confirmation / replacement with a WhatsApp Business number.
- **D10 CSP.** Security headers are strict except `script-src`, which is not locked down (Astro may inline small scripts and the optional analytics are third-party). `frame-ancestors`, `object-src`, `base-uri` and `form-action` are restricted.
- **D11 Netlify Function removed.** `send-email.ts` (and `nodemailer`/`resend`) is replaced by Netlify Forms + Netlify's free email notifications. No server code remains.
